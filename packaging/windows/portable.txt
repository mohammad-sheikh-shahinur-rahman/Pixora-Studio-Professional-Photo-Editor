Pixora Studio portable mode

While this file sits next to photocraft.exe, Pixora Studio keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the PixoraStudioData folder beside it, and writes
nothing to %APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Pixora Studio with its settings.

Delete this file to use the normal per-user folders instead: %APPDATA%\PixoraStudio for settings
and %LOCALAPPDATA%\PixoraStudio\Recovery for crash-recovery autosaves. If PixoraStudioData can't be
written (for example on a read-only drive), Pixora Studio says so and uses those folders instead.
