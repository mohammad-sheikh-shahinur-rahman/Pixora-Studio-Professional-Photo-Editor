Pixora Studio

Professional Photo & Graphics Editing. Free for Everyone.

Layers, masks, adjustment layers, layer styles, typography, vectors, brushes, and true PSD/PSB fidelity — in a native desktop application written entirely in Rust. Cross-platform across Windows, macOS, and Linux. 100% offline, free, and yours.

Built for professionals

Menus, shortcuts, and panels are right where professional editors expect them — without subscriptions, cloud lock-in, or telemetry.

🎛️

Familiar by Design

From Ctrl+J to Ctrl+T, your Photoshop muscle memory works out of the box: identical menus, keyboard shortcuts, tools, and dockable panels.

⚡

Native & Lightning Fast

Pure Rust with a GPU compositor on wgpu (DirectX 12, Vulkan, Metal), tile-based multithreading, and copy-on-write memory. Zero Electron, zero webviews.

🗂️

True PSD/PSB Fidelity

Open, edit, and save layered Photoshop documents with high-fidelity preservation of layer groups, blend modes, masks, and smart objects.

🔒

100% Offline & Free

No subscriptions, no accounts, no cloud dependencies, zero telemetry. Pixora Studio runs completely on your local machine and respects your privacy.

🖼️

Color-Managed Precision

Full ICC workflows on 8-bit, 16-bit integer and 32-bit float pipelines — RGB, Grayscale, CMYK and Lab color spaces with Little CMS 2 integration.

🤖

Automation & MCP Agent Ready

Photoshop Actions (.ATN), Model Context Protocol (MCP) server, and rich headless CLI for batch processing, automated rendering, and AI agent integration.

Built-in Power Scripts New

Accelerate your workflow with comprehensive production utilities built directly into File > Scripts.

📑 Layer Comps to PDF

Flattens each comp over crisp backgrounds and compiles a multi-page presentation PDF instantly.

🏷️ Batch Rename Layers

Bulk search & replace layer names, add prefixes/suffixes, and apply {n} sequential zero-padded numbers.

📱 Export Social Presets

Auto-scales and exports your canvas to Instagram Square, Story, Facebook Post, YouTube Thumbnail, and Twitter in 1-click.

🧩 Split Image to Grid

Divides your canvas into custom rows & columns with auto-numbering — ideal for Instagram carousels and game tilesets.

📐 Export Layout JSON

Generates structured JSON with precise layer coordinates (X, Y), dimensions (W, H), opacity, and blend modes for frontend developers.

🔁 Make Seamless Texture

Applies a 50% coordinate wrap with smart edge cross-blending for repeating 3D game materials and background patterns.

🎨 Color Code Layers by Kind

Auto-organizes layer panels with intuitive color tags: Text (Yellow), Shapes (Orange), Adjustments (Seafoam), Smart Objects (Violet).

🧹 Clean Document Tools

Delete All Hidden Layers, Fit Image (proportional bounds scaling), and Trim Document (transparent edge crop).
