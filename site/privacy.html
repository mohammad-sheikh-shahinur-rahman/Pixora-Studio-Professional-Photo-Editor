Privacy Policy

Published by IT Amadersomaj Inc. · Effective Date: October 25, 2026

1. Our Fundamental Commitment

At Pixora Studio (published by IT Amadersomaj Inc.), we strongly believe that creative software should empower you without compromising your privacy. Our core architectural design principle is simple:

Your creative work belongs entirely to you. Pixora Studio is a 100% offline, local-first desktop application. It does not track you, does not harvest your personal data, and does not send your documents to any remote servers.

2. Information We Do NOT Collect

Pixora Studio does NOT collect, transmit, store, or sell any of the following:

  • Artwork and Files: Your PSD, PSB, TIFF, PNG, JPEG, and native project files remain exclusively on your local storage.
  • Telemetry & Usage Analytics: We do not track which tools you click, how long you edit, or which features you use.
  • Personal Identifiable Information: We do not ask for your name, email address, phone number, or payment details. No user account is required to use Pixora Studio.
  • Hardware & System Scanning: Pixora Studio does not profile your machine or transmit hardware identifiers.

3. Offline AI & Neural Processing

Pixora Studio includes intelligent features such as AI Sky Replacement and Neural Matting. Unlike cloud-dependent editors that upload your private photos to third-party servers for AI processing:

  • All neural networks and machine learning models in Pixora Studio run entirely offline on your computer's local CPU or GPU via native runtimes (ONNX / safe Rust).
  • Not a single pixel or raster tile is ever transmitted over the network for AI segmentation or editing.

4. Local Data Storage & Portability

Any configuration preferences (such as UI panel layouts, recent file shortcuts, and custom presets) are stored strictly locally on your machine:

  • Windows: In your standard local application data folder or within the PixoraStudioData\ folder in portable mode.
  • macOS: In standard ~/Library/Application Support/ directory.
  • Linux: Under standard XDG configuration paths (~/.config/).

You can delete or move this data at any time by simply deleting the local folder.

5. Network Activity

The only optional network actions in Pixora Studio are user-initiated:

  • Checking for Updates: If enabled, the application or package manager (such as AppImage delta updates via .zsync) may query GitHub Releases to compare version numbers. No personally identifiable data is sent.
  • External Documentation Links: Clicking links in the Help menu (e.g. to open GitHub issues or documentation) opens your standard web browser.

6. Website Privacy (GitHub Pages)

Our official website (hosted on GitHub Pages) is a static website. It does not use advertising cookies, marketing pixels, or analytics trackers. Standard server connection logs may be processed by GitHub Inc. in accordance with GitHub's Global Privacy Policy.
